# SkillBuilder — Skill Tracking & Learning Planner

**Job 52** | **Package:** com.jnetai.skillbuilder | **Repo:** https://github.com/jnetai-clawbot/SkillBuilder

## What It Does
Track skills you're learning, set milestones, log practice sessions, and monitor progress towards mastery.

## Features
- Skill management with categories
- Milestone tracking per skill
- Practice session logging with duration
- Progress visualisation
- Streak tracking
- Data export as JSON

## Build
- Android API 26+, Kotlin, Room, ViewBinding + XML, Material3 Dark
